# Film Index 3.0 · 单应用版

一个仓库、一个 Docker 镜像、一个容器、一个 Python 服务进程、一套后台。

订阅与媒体整理已整合进 `film_index` 应用包，注册到同一个 Flask 应用，使用同一个持久登录会话。没有 Nginx 网关、内部 HTTP 代理、第二套后端或独立媒体服务端口。镜像从通用 Python 基础镜像构建，不再继承旧 NAS/媒体项目镜像，也不需要运行原来两个项目。

## 从原项目迁移

1. 停止原百度订阅、Film Index 或三容器 Hub 项目，保留所有文件。不要让新旧实例同时写同一配置目录。
2. 在新项目目录保存 `compose.yaml`，将 `.env.example` 另存为 `.env`。
3. 将 `PAN_CONFIG_DIR` 设为实际包含原 `config.json`、`.session-secret` 和 `history/` 的目录。将 `MEDIA_CONFIG_DIR` 设为原来包含 `config.yaml`、`user.db`、媒体数据库及缓存的目录。`PAN_LOG_DIR` 沿用原日志目录。
4. `MEDIA_ROOT` 沿用原来映射到 `/media` 的宿主机媒体父目录。若以前使用其他容器路径（例如 `/tv`），在 YAML 中额外保留相同路径映射，避免原目录同步规则失效。
5. 创建一个 Compose 项目并启动唯一的 `film-index` 服务，访问 `http://NAS的IP:18520`。
6. 用原百度订阅后台账号密码登录，原有新增后台账号继续有效。媒体模块不再提供第二套账号管理。

```sh
docker compose pull
docker compose up -d
```

原账号、网盘 Cookie、任务 UID、转存记忆直接读取原配置文件，不按目标目录是否存在判断重复。媒体库、目录同步、整理历史、识别词和 TMDB 配置继续读取原媒体配置与数据库。升级前自动备份关键配置和 SQLite 数据库到 `./data/backups`；备份不会清空原数据。媒体软件内保存的旧登录字段保留为兼容数据，不再参与登录。

如果原本有账号任务却看到首次生成密码和空任务，说明配置目录挂载错误。停止新项目并修正路径，不要覆盖原配置。

## 全新安装

飞牛创建 Compose 项目时，只需选择一次项目目录。默认挂载路径会自动相对于该项目目录创建，不必修改占位路径或创建 `.env`：

```yaml
volumes:
  - ./data:/data
  - ./media:/media
```

`data/config` 保存账号、订阅任务和转存记忆，`data/log` 保存日志，`data/media` 保存媒体配置；这些子目录由程序自动创建。`media` 是初始为空的媒体文件目录，程序无法自动判断 NAS 上已有影视文件的位置；需要使用已有媒体时，额外映射其真实目录。已有部署升级应保留原挂载，不应切换到空目录。

仓库 `compose.yaml` 中的 `${变量:-默认路径}` 只是可选的迁移覆盖；不填写变量即使用自动相对路径。首次后台管理员密码显示在容器日志中。后台登录与百度网盘 Cookie 是两回事；过期的网盘 Cookie 仍需更新。

## 运行与界面

保持白色半透明玻璃、纯文字左对齐导航。常用前端页面空闲预热，目录按需异步读取。一个 Waitress 服务器监听 5000，默认 8 请求线程；目录整理和订阅调度在同一进程内运行，不启动 PM2、虚拟显示或浏览器服务。默认 512MiB 是内存上限，实际用量以 NAS 监控为准。

`ffmpeg`、`rclone` 与固定校验版本的 MinIO 客户端包含在镜像中；Rclone 和 MinIO 需挂载原凭据目录。字幕检索所需浏览器仅在执行该功能时启动，并在检索后关闭，不作为独立后台服务运行。PT 下载、做种、站点及索引器功能不启用。

## 构建与源码

```sh
python3 scripts/source_bundle.py
docker build -t film-index:local .
```

整个项目源码在此仓库；网络源码下载入口为 `/project-source.zip`，不包含实际挂载数据、账号密码或 `.env`。沿用原项目许可，按 AGPL-3.0 分发。历史来源与改动记录见 `UPSTREAM.json`。

发布检查包括原账号与新增账号登录、任务和转存记忆保留、媒体数据库持久化、退出和密码变更撤销权限、一个容器/进程/Flask 应用，以及全部保留媒体页面。实际百度网盘和 NAS 媒体文件操作需要部署后使用自己的配置验证。

### v3.0.2

兼容百度分享资料的多行 JSON 数据，临时缺失资料时在同一任务内最多读取三次并重新验证提取码；持续失败仍会报告，不修改转存记忆。新选中 TMDB 资料后，任务名和默认目录使用“片名 (年份)”，已有任务和目录保持原状。


### v3.0.3 任务绑定与分季选项

运行、状态和日志优先绑定稳定任务 ID，修复 0/1 起始序号混用导致相邻行显示运行的问题。列表重排后日志仍属于原任务，已删除任务不会回退运行相邻任务。

新开关默认关闭。电视剧开启“TMDB 自动分季”需绑定 TMDB 并自动命名；它与“强制第一季”互斥，界面自动关闭另一项，后端拒绝冲突配置。明确季号与 TMDB 季集范围核对；只有一个常规季时可自动确定。多季且没有明确季号、季号冲突或超出集数范围时跳过并在日志提示待确认，不把累计集数猜成某一季，也不使用兜底季数。TMDB 请求失败时本次不转存，缓存最多 32 部剧、6 小时。

“按季创建目录”与两种分季方式独立，开启后将其他子目录合并为 `Season 01`、`Season 02`，目录和文件名使用同一季号。开启会启用自动命名，视频和字幕均按此整理；关闭保持原结构规则。转存记忆及同名不覆盖规则保留，历史文件不会因修改选项自动重新转存。


### v3.0.4 目录同步识别修复

修复未配置代理时 TMDB 客户端对空代理执行求值导致识别中断的问题，清除代理后不再保留旧代理。媒体 TMDB 凭据留空时复用订阅 TMDB 凭据，支持 API Key 和 Read Access Token（Bearer 请求头）。原媒体配置的非空凭据优先；订阅凭据保存后立即刷新媒体客户端。空 TMDB 域名使用官方 API 默认地址。

TMDB 认证、网络和非 JSON 响应错误会显示具体原因；失败响应不进入请求缓存。目录同步日志展示 Sync、Meta、Rmt、Scraper 等处理链，并修复时间列折行。真实 NAS 凭据和媒体文件不在本地测试范围；Linux 测试使用模拟 TMDB 响应与临时媒体文件。


### v3.0.5 缩略图性能

镜像内置 FFmpeg。剧集缺少 TMDB 图片时，先输入定位到截帧时间再解码单帧，避免从头解码三分钟。每次截帧上限 15 秒，单线程、最大宽度 640 像素；使用独立临时文件，检查输出成功后原子保存，失败清理临时图片并继续整理。已有图片不重复生成；日志不再对失败截帧报告成功。Linux 发布测试会使用镜像自带 FFmpeg 从临时合成视频生成实际 JPEG，不读取用户网盘媒体。

### v3.0.6 剧集图片识别

优先读取对应 TV ID、季号、集号的 `episodes[].still_path`，与 TMDB 季页面显示的每集图片一致。备用剧集图片接口不继承中文文字语言筛选，允许获取无语言标记的图片；不永久缓存空图片列表。接口查询异常与成功返回无图分开处理：失败时跳过本次缩略图，不启动视频截帧；确认无图才使用限时 FFmpeg。已有本地图片不自动替换。


### v3.0.11 可选目录集数映射

适用于分享方分季与 TMDB 季集编号不一致的订阅。默认关闭，普通订阅的自动识别、过滤、转存记忆与冲突处理保持原样。

在添加或编辑电视剧任务时开启「目录集数映射」，添加相对于分享顶层的完整目录规则，设置目标季数及集数偏移。采用最长目录前缀匹配，不会误匹配相似目录名；不根据文件数量推断偏移。

例如百炼成神：第一季 1–52 → 目标季 1、偏移 0；第二季 53–104 → 目标季 1、偏移 0；第三季 1–26 → 目标季 1、偏移 104，得到 S01E105–S01E130。此后第三季 27 会继续得到 S01E131。请填写实际来源目录名，避免只写不匹配的简称。

只有开启开关且匹配明确目录的文件才应用偏移。支持视频及字幕、正负整数偏移。映射结果必须在 1–9999；开启 TMDB 自动分季时校验目标季集，原目录/文件的季号不再否决明确映射。开启统一第一季时目标季仍为 S01。映射重号在转存之前报错，不覆盖已有文件。

已有转存记忆不会被重置，不会为改规则而重新下载或自动重命名历史文件。旧文件需另行核对后整理。配置映射并不会修改 OpenList、STRM 内容或播放接口。


### v3.0.12 文件名季集映射

「季集映射」现在支持来源目录和文件名通配符两种规则。对于直接放在分享顶层的 S03E01.mp4，在任务中开启季集映射，点「添加文件名规则」，填匹配文件名 `S03E*`、目标季数 `1`、新目录名称 `Season 01`、集数偏移 `104`，保留「仅匹配分享顶层文件」勾选。第一、二季目录内的文件不受这条规则影响。

文件名不区分大小写，支持 * 和 ?，不支持目录或正则表达式；默认只匹配顶层，取消勾选才递归匹配。文件名规则优先于目录规则；多条文件名规则同时命中会跳过并提示。关闭季集映射后文件名规则完全不生效，旧目录规则仍沿用原逻辑。所有规则仍保留范围校验、字幕编号、重号保护和转存记忆。
